# Heart of the Gem's Crochet Website

A static HTML website for a crochet business.

## Files

- `index.html` - Home page
- `about.html` - About page
- `products.html` - Products page
- `blog.html` - Blog page
- `contact.html` - Contact page
- `style.css` - Stylesheet

## How to Host

Upload all files to any web hosting service. Open `index.html` in a browser to view the site.

## Contact Form

The contact form uses `mailto:` to open the user's email client with the form data.
